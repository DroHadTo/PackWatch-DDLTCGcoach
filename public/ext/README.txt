Pack Watch — read-only DDL coach

This MV3 companion runs only on https://ddltcg.com/play. It reads visible,
non-sensitive board text and displays local advice. It never clicks, types,
submits moves, reads credentials, or uploads observations for shared learning.

Install for local testing:

1. Open the browser extensions page.
2. Enable developer mode.
3. Choose "Load unpacked".
4. Select this `public/ext` directory.
5. Open the DDLTCG play page.

The overlay stores only local observation counters in extension storage. The
hosted Packwatch app's local bridge remains the preferred desktop workflow.
Do not use this extension on pages other than the declared DDLTCG play host.
